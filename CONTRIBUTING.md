# Contributing to Markdown Editor

Thank you for your interest in contributing to the Markdown Editor project! This guide will help you get started.

## How to Contribute

### Reporting Issues

If you find a bug or have a feature request:

1. Check if the issue already exists in the [Issues](https://github.com/dataGriff/markdown.editor/issues)
2. If not, create a new issue with a clear title and description
3. Include steps to reproduce (for bugs)
4. Include screenshots if relevant

### Suggesting Enhancements

We welcome enhancement ideas! When suggesting:

1. Explain the use case
2. Describe the expected behavior
3. Consider if it fits the "product manager friendly" goal
4. Be open to discussion and alternatives

### Code Contributions

#### Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/markdown.editor.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test thoroughly
6. Commit with clear messages: `git commit -m "Add feature: description"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Create a Pull Request

#### Code Guidelines

- Keep it simple and user-friendly
- Follow existing code style and patterns
- Comment complex logic
- Test in multiple browsers if possible
- Ensure responsive design works

#### Testing Checklist

Before submitting a PR, verify:

- [ ] Editor loads without errors
- [ ] Markdown preview updates correctly
- [ ] GitHub integration works (load/save)
- [ ] Formatting buttons work
- [ ] Keyboard shortcuts work
- [ ] Responsive design works on mobile
- [ ] No console errors
- [ ] Browser localStorage works correctly

### Areas for Contribution

Here are some ideas where contributions would be valuable:

#### Easy
- Fix typos in documentation
- Improve error messages
- Add more sample content
- Enhance CSS styling

#### Medium
- Add more formatting buttons
- Implement dark mode
- Add keyboard shortcut customization
- Improve mobile experience
- Add file templates

#### Advanced
- File browser for repository navigation
- Multiple file tabs
- Conflict resolution
- Collaborative editing
- Export to PDF/HTML
- Spell checker integration
- Syntax highlighting for code blocks

## Code of Conduct

Be respectful, inclusive, and constructive. We're all here to build something useful together.

## Questions?

Feel free to open an issue for questions or start a discussion.

Thank you for contributing! 🎉
